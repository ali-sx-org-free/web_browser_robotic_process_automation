決定

使用者的決定是 M7 的 D9（2026-11-06 18:21 America/Los_Angeles（PST，UTC−08:00），照建議）：資料驅動做成批次執行，一列一次執行、各有報告，匯總頁可以匯出、可以只重跑失敗的列；「一次執行裡逐項做」由 forEach 負責。下面是這次細部設計的實作選擇（沒有另外問使用者，審閱時可以改），理由見 ADR 0024：

#項目選擇
I1一列是什麼一次一般的正式執行（目的 execution），記下 runs.batch_id、batch_row；版本在建立批次時固定。Worker、錄製端、執行器不知道批次。
I2表格貼上（Tab 或逗號分隔）或上傳 CSV、TSV、xlsx（第一個工作表；UTF-8、帶 BOM、Big5 的 CSV 都讀得出來；.xls 說明要另存成 .xlsx）。第一列是標題；最多 1,000 列、50 欄、5 MB、每格 10,000 字。儲存格存成文字，排入前才換算。
I3欄位對應與換算依標題自動對應（相同，或不分大小寫、忽略空白、底線與連字號後相同），可以改成別的欄位或不對應；空白用預設值。數字可以有千分位；是非收 true／false、1／0、yes／no、y／n、是／否、對／錯；清單與物件寫 JSON；{{ }} 照原樣交給動態值；檔案入參不能從表格給值。換算後照契約檢查，有問題的列不執行。
I4先建立再開始建立後是 draft：可以改欄位對應與選項、刪除；開始後不能改。M7 任務紀錄寫「開始前逐列校驗」，做成建立後在批次頁看每一列的檢查。Agent API 建立後直接開始（任何一列有問題就整批不建立）。
I5排程每一次執行結束（含排隊中被取消）就從資料庫重新算：補滿「同時幾列」（1～10）或結束；冪等鍵「批次-列號-第幾次」；伺服器啟動時接著走。「第幾輪」區分這一輪要跑的列（開始是 1，每次重跑加 1），沒被選的列不跟著跑，上一輪排不進去的列不會讓「一列沒通過就停下」立刻停下。
I6停下「一列沒通過就停下」：不再排新的列，等已經在跑的跑完才標成 stopped；手動停下：馬上 stopped，取消排隊中與執行中的列。已經在目標系統完成的動作不會回滾。
I7匯出與 xlsx伺服器產生 CSV（UTF-8 帶 BOM；以 =、+、-、@ 開頭又不是數字的值加 '）與 xlsx（凍結標題列）。伺服器用標準函式庫讀寫 xlsx，不加 openpyxl（加了分發包的 runtime 會變，升級要下載完整安裝包）。
I8Agent API 與範圍POST /agent-api/v1/batches 一列一組入參（需要 runs:execute），讀結果需要 runs:read；同時排入的列算在排隊與執行中的上限裡；只看得到、停得了自己建立的批次。第一版只有發布過的場景；M7 任務紀錄第 6 節提到的「專案裡的組合場景」之後再看需求。

人工驗收（建議步驟，未執行）

  • 建立與檢查：匯入範例，驗證並發布 BA-001。場景頁按「批次執行」，貼上 title、quantity 兩欄、四列（其中一列數量寫 99、一列數量寫 1,000）；建立後批次頁兩列標成「資料有問題」並說明原因，其餘「等待中」。把 title 改成「不對應」存檔，每一列的標題都用預設值。
  • 同時幾列與運行紀錄：「同時幾列」設 2 開始：運行報告裡出現兩筆排隊或執行中的正式執行，一筆結束就補下一筆；批次頁自動更新；每一列連到自己的運行詳情與回看，出參欄有建立的紀錄編號。只有本機 Worker 時一次跑一列。
  • 失敗與重跑：驗證並發布 BA-002，貼上一欄 recordId：上一步建立的兩個編號，加一個不存在的 DEMO-NOPE1。結束後那一列「失敗」，其他通過；把那一格改成存在的編號按「重跑沒有通過的列」，只跑那一列，第二次通過，「第幾次」是 2，運行紀錄兩次都在。
  • 一列沒通過就停下：同一張表把不存在的編號放第一列、選「一列沒通過就停下」、同時 1 列：第一列失敗後批次「已停下」，其餘列「沒有執行」。
  • 手動停下：BA-001 十列、同時 2 列，開始後按「停下」：排隊中與執行中的列取消，其餘沒有執行；目標網站上已經建立的紀錄不會消失。
  • 匯出：下載 CSV 用 Excel 打開不亂碼；標題以 = 開頭的值顯示成文字、不是公式；下載 Excel 打開看得到每一列的狀態、執行編號與出參，標題列凍結。把匯出的 Excel（或自己用 Excel 存的 .xlsx，含日期欄）上傳成新的批次，欄位與值讀得出來。
  • 重啟：批次執行中停掉伺服器再啟動：執行到一半的那一列照一般規則標成失敗，批次接著排剩下的列。
  • Agent API：用有 runs:execute、runs:read 的金鑰 POST /agent-api/v1/batches（範例見使用指南），GET /batches/{id} 看每一列的結果；另一把金鑰讀同一個批次回 404。
