Python 瀏覽器節點的運行回看

相容模式（沒寫 script.runtime）的 Python 腳本自己開瀏覽器；錄影開著時替它錄影，run.step() 的步驟在影片上定位，回看頁和 DSL 場景一樣是播放器。腳本不用改。
