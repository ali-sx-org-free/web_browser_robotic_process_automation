原因

  • 失敗的運行：issue #8：每晚完整測試 run 42698747699（2026-11-09 13:02 America/Los_Angeles（PST，UTC−08:00）開始，main 8c0e7ad），只有「完整測試（windows-latest，Python 3.13）」第 1 遍失敗（1 failed、2231 passed），瀏覽器測試再跑的第 2、3 遍與 Ubuntu、macOS 都通過。issue #7：一鍵安裝腳本 run 42703656541（13:33 開始，同一個 SHA），「專案內執行（windows-latest）」與「從零開始（windows-latest）」的 setup.ps1 最後跑測試時失敗；Linux、macOS、Rocky 8 都通過。三個 job 失敗的都只有這一個測試，錯誤是 FileNotFoundError: [Errno 2] No such file or directory: 'a:b.csv'。
  • 為什麼：測試先真的建立 outputs/a:b.csv，確認 pack_directory 會跳過 Portal 不接受的檔名。Windows 上 pathlib 把 a: 當成磁碟機代號，tmp_path / "outputs" / "a:b.csv" 整個變成 WindowsPath('a:b.csv')（A 槽上的相對路徑）；就算不被當成磁碟機，Windows 檔名也不能有冒號。本地以 PureWindowsPath('C:/Users/x/run') / 'outputs' / 'a:b.csv' 重現，結果是 PureWindowsPath('a:b.csv')。
  • 為什麼現在才出現：這個測試由 d1b440f（2026-10-29 23:37 America/Los_Angeles（PDT，UTC−07:00））加入。PR 的 CI 在 Windows 只跑 -m "browser and (role_worker or smoke)"，一鍵安裝腳本在 PR 上也只跑冒煙測試（role 範圍），Windows 上不需要瀏覽器的測試只在排程（或手動選 full）裡跑；這兩次是倉庫搬到 ali-sx-org-free 之後的第一次排程（每晚完整測試 run_number 1）。
