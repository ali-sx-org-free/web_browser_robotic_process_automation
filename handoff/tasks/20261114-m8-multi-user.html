#項目內容
D1登入方式先只做本地帳號；users.provider、subject 預留給 OIDC、LDAP。
D2權限單位以領域為單位：管理員、編輯者、執行者、檢視者，管場景、組合場景、執行、回看（與批次）；另有系統管理員。
D3SecretsAES-GCM（cryptography）；金鑰自動產生存成 0600 的 secrets.key，RPA_SECRETS_KEY 可以覆寫；Secrets 維持全域、只有系統管理員能改；接受這次升級要換完整分發包。
D4升級模式一律要登入；第一個系統管理員只能在伺服器那台（127.0.0.1）建立；裝置配對與 Agent API 金鑰照舊。
I1密碼與工作階段scrypt（N=2^15）；密碼至少 8 個字；Cookie 是隨機權杖、名稱加伺服器代號、HttpOnly、SameSite=Lax；7 天沒用失效、最長 30 天；15 分鐘內輸錯 5 次暫停。
I2權限的寫法登入關卡的規則表（第一個符合的；沒列出的寫入預設拒絕），看不到 404、不能做 403；建立時才指定領域的在路由裡再檢查。
I3清單篩選目前的使用者放 ContextVar，服務層的清單只列看得到的領域；背景工作不受限制。
I4稽核登入、登入失敗、登出、建立第一個管理員與每一個 /api 寫入請求（不含內容）；雜湊鏈，頁面上方顯示驗證結果。
I5帳號管理不刪除只停用；最後一個系統管理員不能拿掉；不能停用自己；rpa user create／password 給沒有瀏覽器的伺服器與忘記密碼時用。
I6開放的路徑API 的說明（openapi.json、docs）不必登入：rpa serve 用它認出已經在執行的 Portal。
I7舊的測試Settings.skip_login（from_env 不讀）讓 M8 之前的測試當成系統管理員；登入與權限有自己的測試。
I8介面右上角顯示自己的名稱與登出；只有系統管理員能用的選單不顯示；批次清單的共用上限只給系統管理員看；「本機 · 單一使用者」改成「本機部署」。
I9錄製端的閘道沒登入的 401 帶 X-RPA-Login: required；閘道照樣轉送，不呼叫 on_unauthorized（不當成裝置權杖失效）。桌面端的端到端測試先在伺服器這台建立 CI 的系統管理員，經由閘道時也先登入。
I10被擋下的寫入沒有權限被登入關卡擋下的 /api 寫入（403、404）也記進稽核紀錄（2026-11-14 寫驗收教程時發現原本沒記）。
I11解不開的 Secrets金鑰換過或不見時，「登入與憑證」標成「解不開」並說明怎麼補救；場景與組合場景執行前的檢查當成沒有設定（原本顯示「已設定」、執行時才失敗）。Secrets 表單的說明改成加密與金鑰檔；透過錄製端時頁首的「單一使用者」拿掉。

人工驗收（建議步驟，未執行）

  • 第一個系統管理員：用新的資料夾啟動（uv run rpa serve --data data-m8），瀏覽器打開 http://127.0.0.1:8080：轉到「建立第一個系統管理員」，建立後直接登入，右上角是自己的名稱。從別台電腦（或錄製端）打開只看到說明。
  • 帳號與成員：「管理後台 › 帳號」新增 amy、bob；「測試網站自動化」領域頁下面的「成員」把 amy 設成執行者、bob 設成檢視者。用另一個瀏覽器（或無痕視窗）登入 amy：只看到這個領域；可以執行 BA-001，打不開編輯頁（403）；選單沒有裝置、API 用戶端、帳號、稽核紀錄。bob 執行時回 403。
  • 看不到的領域：新增領域「人資」，不把 amy 加進去：amy 的清單沒有它，直接打開 /domains/hr 是 404。
  • 密碼：amy 在「我的帳號」改密碼後，另一個已登入的 amy 視窗要重新登入；系統管理員重設 amy 的密碼或停用 amy 後，amy 的登入都失效。連續輸錯 5 次會暫停登入 15 分鐘。
  • Secrets：升級前已設定的 Secrets 在升級後照樣能用（執行時有值），資料目錄的 secrets.json 裡看不到明文，多了 secrets.key。amy 不能設定或刪除 Secrets。
  • 稽核紀錄：「管理後台 › 稽核紀錄」看得到上面的登入、新增帳號、成員、執行請求與登入失敗，上方顯示雜湊鏈完整。
  • 沒有瀏覽器的伺服器：另一個資料夾執行 uv run rpa user create root --admin --data data-cli 後用它啟動，直接用 root 登入；uv run rpa user password root --data data-cli 重設密碼。
  • 錄製端與 Worker：已配對的錄製端打開管理 Portal 時先登入，之後錄製、調試照常；Worker 照常領取與執行；Agent API 照常用金鑰。
